# Лабораторна робота 2 — Алгоритми обробки масивів

N = 20, K = 3, a = 2, b = 0, c = 0

## Мета роботи

Навчитися реалізовувати алгоритми обробки одновимірних масивів і матриць мовою C# за допомогою циклів та умов.

## Виконані завдання

1. `AnalyzeArray` — обчислення суми, середнього, мінімуму, максимуму, їхніх індексів і кількості нулів за один прохід.
2. `FilterArray` — створення нового масиву з елементів, менших за 3.
3. `FindLongestSeries` — пошук найдовшої серії однакових елементів, її довжини та початкового індексу.
4. `ReverseArray` — реверс масиву без створення другого масиву.
5. `ProcessMatrix` — виведення матриці 4 × 5, обчислення сум рядків, максимумів стовпців і рядка з найбільшою сумою.
6. Перевірка крайових випадків для порожнього масиву, одного елемента та масиву з однакових значень.
