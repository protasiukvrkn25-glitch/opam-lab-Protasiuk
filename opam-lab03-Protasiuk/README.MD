# Лабораторна робота 3 — Рекурсивні алгоритми

N = 20, K = 3, a = 2, b = 0, c = 0

## Мета роботи

Навчитися використовувати рекурсію для обходу каталогів, поділу задачі навпіл і генерації перестановок.

## Виконані завдання

1. `GetDirectorySize` — рекурсивно обчислює сумарний розмір файлів у каталозі та вкладених папках. Базовий випадок: у папці немає вкладених каталогів, тому цикл рекурсивних викликів не виконується.
2. `Solve` — перевіряє, чи всі елементи масиву однакові, поділяючи його на дві частини. Базовий випадок: частина містить один елемент або є порожньою.
3. `GeneratePermutations` — генерує всі перестановки літер В, А, Д. Базовий випадок: позиція `start` дорівнює довжині масиву.
4. `SolveTraced` — виводить входи та виходи рекурсивних викликів.
5. `SolveIterative` — перевіряє однаковість елементів за допомогою циклу.

## Результати завдання 3

Очікувана кількість перестановок: 6.

## Завдання 4. Трасування

Вставити сюди фактичний вивід програми для масиву `[7, -2, 15, 4]`.

Рядки `enter` з'являються під час заглиблення рекурсії. Рядки `exit` з'являються у зворотному порядку, оскільки кожен виклик завершується лише після повернення результатів вкладених викликів.

## Завдання 5. Порівняння

Рекурсивний алгоритм наочно показує поділ масиву на частини, але потребує додаткових викликів функції. Циклічний варіант для перевірки однаковості простіший і використовує менше додаткової пам'яті.

Під час ітеративного обходу каталогів потрібно вручну зберігати шляхи до папок, які ще треба обробити. Для цього можна використати стек або чергу, оскільки звичайний цикл сам не запам'ятовує вкладені каталоги.

## Перевірка крайових випадків

| Вхід | Завдання | Очікувано | Отримано |
|---|---|---|---|
| Порожня папка | 1 | 0 байтів | Заповнити після запуску |
| Папка без доступу | 1 | Повідомлення, програма не падає | Перевірити за наявності такої папки |
| Масив з одного елемента | 2 | `true` | `true` |
| Усі елементи однакові | 2 | `true` | `true` |
| Варіантів не існує | 3 | Для літер ВАД такого випадку немає; генеруються 6 перестановок | 6 перестановок |
